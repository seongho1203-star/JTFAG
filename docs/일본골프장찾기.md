# 일본 골프장 찾기 켜기 (라쿠텐 GORA)

한 번만 해 두면 되는 설정이다. 다 하면 여행 일정(🧳)에서 일본 여행을 만들고
날마다 **🔎 일본 골프장 찾기**를 누르면, 숙소 주변에서 **그날 예약 가능한 골프장**이
지도와 목록(가까운 순 · 가격 · 시간대)으로 뜬다.

## 무엇을 하고 무엇을 못 하나

| 된다 | 안 된다 |
|---|---|
| 숙소·역 기준 거리 범위로 골프장 찾기 | 앱 안에서 예약·결제 |
| 그날 빈자리가 있는 플랜·최저가·시간대 | 라쿠텐 회원 로그인 대신 해 주기 |
| 지도에 숙소와 골프장을 같이 표시 | |
| 고른 골프장을 그 날짜 일정에 넣기 | |
| GORA 예약 페이지 열기 (사파리 번역으로 한국어) | |

**라쿠텐은 예약을 대신 해 주는 API를 열어 두지 않았다.** 그래서 예약은
`🎫 GORA에서 예약`을 눌러 GORA 사이트에서 사람이 한다. 일본어 화면은 사파리 메뉴(≡ 또는 주소창의 `가가`)의
`번역 → 한국어`로 본다. (구글 번역 링크는 한국에서 막혀 있어 뺐다.)

```
앱(trip.js) ── Supabase 함수 gora ── 라쿠텐 GORA 플랜 검색 API
                  (열쇠는 여기에만)
```

**열쇠는 앱에 두지 않는다.** 저장소가 공개라 앱 코드에 넣으면 그대로 새어 나간다.
대화창에 붙여 넣지도 말 것 — 아래 2번처럼 Supabase에만 넣는다.

---

## 1. 라쿠텐 앱 등록 (열쇠 받기)

1. 라쿠텐 회원으로 로그인한다 (GORA 예약하던 계정 그대로 된다).
2. <https://webservice.rakuten.co.jp/> 에서 **アプリID発行** (앱 ID 발급)을 누른다.
3. 칸은 이렇게 적는다.

| 칸 | 값 |
|---|---|
| アプリ名 (앱 이름) | `JTFAG` |
| アプリURL (앱 주소) | `https://seongho1203-star.github.io/JTFAG/` |
| 許可されたWebサイト (허용된 웹사이트) | `seongho1203-star.github.io` |

   그리고 맨 아래 **API Access Scopes**에서 **Rakuten GORA API**를 꼭 체크한다
   (빠지면 `403 REQUESTED_SCOPES_NOT_ALLOWED`가 뜬다).
   Allowed websites에는 `xhulylksiexhtifyrokp.supabase.co`도 한 줄 더 넣어 두었다.
4. 다 하면 두 값이 나온다. 복사해 둔다.
   - **アプリID (applicationId)** — 하이픈 섞인 긴 영숫자
   - **アクセスキー (accessKey)** — `pk_` 로 시작

> 라쿠텐은 2026년에 API를 바꿨다(주소가 `openapi.rakuten.co.jp`로 바뀌고 액세스 키가 새로 생겼다).
> 예전에 만든 앱 ID만 있으면 안 되고, 새로 등록해 두 값을 다 받아야 한다.

---

## 2. Supabase에 열쇠 넣기

Supabase 대시보드 → 프로젝트 → **Edge Functions → Secrets** → **Add new secret** 으로 둘을 넣는다.

| Name | Value |
|---|---|
| `RAKUTEN_APP_ID` | 1번의 アプリID |
| `RAKUTEN_ACCESS_KEY` | 1번의 アクセスキー (`pk_...`) |

허용된 웹사이트를 다른 주소로 적었다면 `RAKUTEN_REFERER`에 그 주소를 넣는다
(기본값 `https://seongho1203-star.github.io/JTFAG/`).

---

## 3. 함수 올리기

Supabase 대시보드 → **Edge Functions** → **Deploy a new function**

| 칸 | 값 |
|---|---|
| **Name** | `gora` ← **이름이 정확해야 한다** |

편집기에 `supabase/functions/gora/index.ts` 내용을 통째로 붙여 넣고 **Deploy**.

---

## 4. 확인

1. 앱 → 🧳 여행 → `＋ 새 여행` → 어디로? **🇯🇵 일본** → 만들기
2. 아무 날의 `🔎 일본 골프장 찾기`
3. 기준 위치에 `신주쿠`(또는 숙소 이름) → 찾기 → 하나 고르기
4. `⛳ 그날 예약 가능한 골프장 찾기`

| 화면에 뜨는 말 | 뜻 |
|---|---|
| `아직 라쿠텐과 연결되지 않았습니다` | 2번(열쇠) 또는 3번(함수 이름 `gora`)이 빠졌다 |
| `… 403 · REQUESTED_SCOPES_NOT_ALLOWED` | 라쿠텐 앱의 API Access Scopes에 GORA가 안 켜져 있다 |
| `라쿠텐에서 답을 받지 못했습니다 · 403 …` (그 밖) | 허용된 웹사이트 주소가 `RAKUTEN_REFERER`와 다르다 |
| `… 400 · wrong_parameter …` | 묻는 칸 이름이 라쿠텐과 다르다 — 그 화면을 찍어 보내 주면 앱만 고치면 된다(함수는 다시 안 올려도 된다) |
| `그날 예약 가능한 곳이 없습니다` | 정상. 범위·금액을 넓혀 본다(예약은 보통 두세 달 앞까지 열린다) |

## 함수는 왜 얇은가

함수는 받은 칸 이름을 정해 둔 목록에서만 골라 라쿠텐에 그대로 넘기고, 답도 그대로 돌려준다.
**무엇을 어떻게 물을지는 앱(`trip.js`)이 정한다** — 그래야 고칠 일이 생겨도 이 화면에서
함수를 다시 붙여 넣을 필요 없이 앱만 밀면 된다.
