# 정산 금액 분리 저장 켜기

정산 금액(시작 · 남은 · 찬조)을 앱 데이터 한 덩어리에서 떼어 **칸마다 따로** 저장하는 설정이다.
Supabase에 테이블 하나를 만들면 켜진다. **한 번만 하면 된다.**

## 왜 필요한가

예전에는 금액이 앱 데이터 한 덩어리(`jtfag_league.payload`) 안에 있었다. 그래서 누가 무엇을
저장하든 — 금액이든 일정이든 사진이든 — **네 명의 금액 전체를 그 폰이 마지막으로 본 상태로
다시 써 넣었다.** 넷이 동시에 적거나, 실시간을 놓친 폰이 하나라도 저장하면 이런 일이 생겼다.

- 다른 사람 금액이 0이 된다
- 100,000을 적었는데 좀 있다 보면 0이 되어 있다
- 금액을 고쳤는데 다시 옛 값으로 돌아간다

앱 화면 네 개를 띄워 같은 DB를 나눠 쓰게 하고 동시에 입력해 보면 이 세 가지가 그대로 재현된다.
금액 테이블을 쓰면 같은 상황에서 하나도 안 생긴다.

## 켜는 방법 (5분)

1. [Supabase 대시보드](https://supabase.com/dashboard)에 들어가 이 앱의 프로젝트를 고른다.
2. 왼쪽 메뉴에서 **SQL Editor**를 누르고 **New query**를 연다.
3. 저장소의 [`supabase/money.sql`](../supabase/money.sql) 내용을 **통째로** 붙여 넣고 **Run**을 누른다.
4. 아래쪽에 `Success. No rows returned`가 뜨면 끝이다. (여러 번 돌려도 안전하다.)
5. **네 명 모두 앱을 새로 연다.** 홈 화면에 깔아 둔 앱은 완전히 닫았다가 다시 연다 —
   예전 코드가 떠 있는 폰은 금액을 예전 방식으로 쓴다. 넷이 다 다시 열기 전까지는 폰끼리 금액이
   다르게 보일 수 있다(새 방식으로 적은 금액이 예전 폰에는 안 보인다). 다시 열면 맞춰진다.
   **새 방식 폰이 적은 금액은 예전 폰이 무엇을 저장해도 지워지지 않는다.**

## 켜졌는지 확인

앱을 열면 위쪽 저장 상태 문구가 **`⚡ 연결 완료 · 금액 분리 저장`**으로 나온다.
`⚡ Supabase 연결 완료`만 나오면 아직 예전 방식이다 — 3번을 다시 확인한다.

처음 연 폰이 지난 차수 금액을 새 테이블로 옮겨 놓는다. 지난 금액은 그대로 보여야 한다.

## 다른 사람이 고친 금액이 바로 안 보이면

SQL이 실시간 목록에도 테이블을 넣는데, 혹시 빠졌으면
**Database → Publications → `supabase_realtime`**에서 `jtfag_money`를 켠다.
(안 켜져 있어도 금액이 지워지지는 않는다. 앱을 다시 열면 맞는 값이 보인다.)

## 알아 둘 것

- 테이블을 만들기 전에는 **예전 방식 그대로** 돈다. 앱이 망가지지는 않는다.
- 행을 지우는 권한은 일부러 안 준다. 금액은 0으로 덮어 지운다.
- 골퍼가 바뀌면 `money.sql`의 이름 목록(`'이관교', '김지명', '신성호', '박승수'`)을 고쳐서 다시 돌린다.
  목록에 없는 이름은 저장이 거절된다.
