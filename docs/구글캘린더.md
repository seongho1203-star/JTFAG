# 구글 캘린더 자동 등록 켜는 법

앱에서 **다음 라운드 일정**이나 **여행 일정**을 저장하면, 내 구글 캘린더에 이벤트가 저절로 생기고
고치거나 지우면 따라갑니다. 앱 코드는 이미 들어가 있고, **구글 쪽 준비와 Supabase 함수 올리기**만 하면 켜집니다.
**PC에서 하는 것을 권합니다**(구글 클라우드 화면이 폰에서는 다루기 힘듭니다).

## 어떻게 돌아가나

```
앱에서 일정 저장 → Supabase 함수 calendar-sync 호출
  → 함수가 DB에서 일정을 읽어 → 구글 캘린더 이벤트와 맞춤
```

- 라운드는 `⛳ 11차 라운드 · 무등산CC`로, 티오프 시각이 있으면 그 시각부터 5시간짜리 이벤트가 됩니다.
- 여행은 기간 전체 한 줄(`🧳 10월 남도 골프 여행`, 일정에서 '바쁨'으로 안 잡힘)과 라운드가 있는 날마다 한 줄입니다.
  티오프가 비어 있으면 종일 이벤트입니다.
- 앱이 만든 이벤트에만 표시(`jtfag=1`)가 붙습니다. **내가 직접 넣은 일정은 절대 안 건드립니다.**
- 이미 지난 이벤트는 안 지웁니다. 날짜를 앞으로 옮기거나 여행을 지우면 그 이벤트가 지워집니다.
- 설정 전이거나 함수가 없어도 앱은 아무 오류 없이 그대로 돕니다.

## 1. 구글 클라우드에서 서비스 계정 만들기 (한 번만)

내 구글 계정으로 로그인해 로그인 대신 쓰는 **서비스 계정**을 만듭니다. (일반 로그인 방식은 7일마다 끊겨서 안 씁니다.)

1. https://console.cloud.google.com 에서 새 프로젝트를 만든다 (이름은 아무거나, 예: `jtfag`).
2. 왼쪽 메뉴 `API 및 서비스` → `라이브러리` → **Google Calendar API**를 찾아 `사용`을 누른다.
3. `API 및 서비스` → `사용자 인증 정보` → `사용자 인증 정보 만들기` → **서비스 계정**.
   이름은 아무거나(`jtfag-calendar`), 역할은 비워 두고 완료.
4. 만든 서비스 계정을 눌러 `키` 탭 → `키 추가` → `새 키 만들기` → **JSON** → 만들기.
   JSON 파일이 내려받아진다. **이 파일이 비밀번호다. 저장소·카톡·대화창에 올리지 말 것.**
5. 서비스 계정 화면에서 **이메일 주소**(`jtfag-calendar@프로젝트.iam.gserviceaccount.com`)를 복사해 둔다.

## 2. 내 캘린더를 그 계정과 공유하기

1. https://calendar.google.com → 왼쪽 `내 캘린더`에서 이벤트를 넣을 캘린더 → `⋮` → `설정 및 공유`.
2. `특정 사용자 또는 그룹과 공유` → `사용자 추가` → 위에서 복사한 서비스 계정 이메일 입력.
3. 권한은 **`일정 변경 및 공유 관리`가 아니라 `일정 변경`**(이벤트 수정)으로 정하고 `보내기`.
4. 같은 설정 화면 아래쪽 `캘린더 통합`의 **캘린더 ID**를 복사해 둔다.
   (기본 캘린더는 내 구글 이메일 주소 그대로다.)

## 3. Supabase에 함수와 비밀값 올리기

1. Supabase 화면 → `Edge Functions` → 새 함수 `calendar-sync` 만들기 → `supabase/functions/calendar-sync/index.ts`의 내용을 **통째로 붙여넣고** 배포.
   (함수 이름은 반드시 `calendar-sync`.)
2. 같은 화면의 `Secrets`(비밀값)에 둘을 넣는다.
   - `GOOGLE_SA_JSON` — 내려받은 JSON 파일의 **내용 전체**를 그대로 붙여넣기
   - `GCAL_CALENDAR_ID` — 2번 4단계에서 복사한 캘린더 ID

## 4. 확인

앱에서 일정 창에서 다음 라운드 날짜·시각을 다시 저장해 보면 몇 초 안에 구글 캘린더에 이벤트가 생깁니다.
이미 잡아 둔 일정은 **한 번 저장해야** 처음 올라갑니다(앱은 '바뀐 저장'이 있을 때만 함수를 부릅니다).

안 생기면 Supabase `Edge Functions` → `calendar-sync` → `Logs`를 보세요.
- `not_configured` — 비밀값 둘 중 하나가 빠졌다.
- `구글 인증 실패` — `GOOGLE_SA_JSON`이 잘렸거나 Google Calendar API를 `사용`하지 않았다.
- `캘린더 목록 실패: 404` — 캘린더 ID가 틀렸거나 서비스 계정과 공유하지 않았다.
- `403` — 공유 권한이 `일정 보기`뿐이다. `일정 변경`으로 올릴 것.

## 시험

`node --experimental-strip-types tests/calendar-sync.js` — 가짜 구글·가짜 DB로 생성·수정·삭제·되살리기·남의 일정 보존을 확인한다(실제 캘린더를 안 건드린다).
