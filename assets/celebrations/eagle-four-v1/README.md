# 독수리 4연속 · 불패의 군림

`eagle-four.mp4`는 불꽃빛 테마의 12초·720×1280·30fps 시네마틱 영상이다. 네 번의 금빛 표시와 타격음, 불꽃빛 후광, `4연속 독수리` 타이틀을 사용한다. 원본 이미지·글꼴·프롬프트·재생 방식은 [공통 제작 정보](../eagle-three-v1/README.md)에 있다. 영상 안의 카메라·색보정·입자·효과음을 별도로 렌더링했으며 생성 원본은 변경하지 않았다.

```bash
python3 scripts/render-eagle-film.py --streak 4
node tests/eagle-film.js
```

앱은 실제 이름·4개 차수·타수를 겹쳐 표시한다. 자동 재생·뱃지 재생·관리자 미리보기에서 정확히 4연속에만 선택된다. 영상과 포스터는 처음 볼 때 각각 저장한다.
