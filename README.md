📄 ⁠index.html⁠ (메인 뷰 & 구조)
 역할: 애플리케이션의 뼈대이자 전체 UI 골격을 담당합니다.
 주요 기능:
 통합 정산 요약, 스코어 입력표, 정산 내역 등 모든 UI 요소의 컨테이너를 정의합니다.
 외부 폰트(Pretendard) 및 필요한 JS/CSS 파일들을 로드합니다.
 모달(Modal) 창들(명예의 전당, 사진 갤러리, 일정 등)의 기본 구조를 포함합니다.
🎨 ⁠style.css⁠ (스타일링 & 애니메이션)
 역할: 앱의 시각적인 디자인, 레이아웃, 모바일 최적화 및 애니메이션을 담당합니다.
 주요 기능:
 모바일 최적화 (Responsive Design): 스마트폰 화면에 꽉 차고 스크롤이 편리하도록 UI를 설계했습니다.
 틀고정 (Sticky Layout): 엑셀처럼 스코어 입력표에서 '이름' 열이 좌우 스크롤 시에도 화면 좌측에 고정되도록 처리합니다.
 시각 효과 (Visual Effects): 계급별 고유 테두리(Glow), 명예의 전당 오픈 시 금빛 회전 애니메이션, 슬롯머신(Count-up) 효과 등 생동감 넘치는 디자인을 구현합니다.
 CSS Grid 및 Flexbox를 활용한 깔끔한 데이터 정렬.
⚙️ ⁠api.js⁠ (데이터베이스 통신 & 전역 상태 관리)
 역할: Supabase와의 실시간 데이터 통신(BaaS) 및 앱의 기본 데이터(State)를 관리합니다.
 주요 기능:
 Supabase 연동: 실시간 데이터베이스(PostgreSQL)의 조회, 수정, 실시간 구독(Real-time Subscribe) 로직을 처리하여, 한 명이 데이터를 수정하면 모든 동반자의 화면이 즉시 업데이트됩니다.
 전역 상태 (Global State): ⁠appData⁠ 객체를 통해 이름, 코스, 타수, 공금, 정산 금액 등 모든 플레이 데이터를 중앙에서 관리합니다.
 외부 API 연동: Open-Meteo API를 호출하여 입력된 골프장 위치(위/경도) 기반의 실시간 날씨 및 일일 예보를 가져옵니다.
 랭크 설정: 커스텀 이미지 아이콘과 페널티 금액이 정의된 랭크 환경 설정(⁠RANK_CONFIG⁠)을 포함합니다.
🧮 ⁠calc.js⁠ (핵심 비즈니스 로직 & 정산 엔진)
 역할: 골프 타수 기반의 복잡한 정산, 핸디캡 계산, 뱃지 부여, 통계 산출을 담당하는 핵심 엔진입니다.
 주요 기능:
 1:1 매치플레이 정산: 누적 2라운드 평균 타수를 기준으로 핸디캡을 산출하고, 이를 바탕으로 라운드별 1:1 승/무/패를 계산하여 계급(독수리, 매, 학, 참새)을 결정합니다.
 통합 요약 산출: 계급별 페널티 정산 금액과 실제 타수당 정산 금액을 합산하여 최종 손익(Net Profit)을 계산합니다.
 명예의 전당 통계: 통산 승률, 누적 버디/파/양파 횟수, 기복, 최소/최대 타수 등을 계산하여 개인별 스탯을 도출합니다.
 동적 뱃지 생성: 특정 조건(독수리 3연속, 평균 타수 1위, 기부왕 등)을 달성한 인원에게 부여할 칭호와 뱃지를 자동으로 판별하여 배열로 반환합니다.
📱 ⁠ui.js⁠ (화면 렌더링 & 사용자 인터랙션)
 역할: 사용자의 터치(클릭) 이벤트 처리, 데이터 시각화(렌더링), 브라우저 네이티브 기능 제어를 담당합니다.
 주요 기능:
 데이터 렌더링: ⁠calc.js⁠에서 계산된 데이터를 바탕으로 HTML DOM 요소(스코어보드, 요약 카드, 정산 내역 등)를 동적으로 그려냅니다.
 모달 제어: 명예의 전당, 사진 갤러리 뷰어, 라운드 추가/삭제 등의 UI 팝업을 열고 닫는 로직을 관리합니다.
 기기 맞춤형 인사 (Local Storage): 브라우저 캐시를 이용해 본인의 이름을 기억하고, 앱 접속 시 혹은 명예의 전당 오픈 시 해당 계급에 맞는 오디오(독수리 전용 사운드 등) 재생 및 화면 블러 효과를 연출합니다.
 유틸리티 기능: 카카오톡 다이렉트 공유(Intent), 기기 갤러리에 이미지 다운로드(Base64 처리) 등 모바일 특화 편의 기능을 실행합니다.
